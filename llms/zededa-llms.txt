# ZEDEDA

> ZEDEDA is an edge intelligence platform that lets enterprises deploy, manage, and secure AI workloads and applications across thousands of distributed edge sites. Its ZedCloud control plane orchestrates EVE-OS edge nodes, edge applications, networks, storage, and managed Kubernetes (ZKS) through a REST API.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public Swagger specifications and developer surface. Not fabricated; every link resolves to a real ZEDEDA resource.

## API

The ZedCloud API is served under `https://zedcontrol.zededa.net/api` (v1). Authentication is via an `X-API-KEY` header (long-lived API key) or an `Authorization` bearer token (user session). The surface is grpc-gateway generated and split into 10 services totaling 421 operations. Errors return a `google.rpc.Status` body plus a granular `ZsrvError` code.

- API docs: https://zedcontrol.zededa.net/api/v1/docs/
- Terraform provider (official): https://registry.terraform.io/providers/zededa/zedcloud/latest
- Example scripts (official): https://github.com/ZEDEDA/examples
